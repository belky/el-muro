# EL MURO

Aventura de ficción interactiva en español. Drama histórico · Berlín — 1961.

Berlín Oriental, 13 de agosto de 1961. Esta noche empieza la construcción del Muro. Tienes pocas horas para cruzar al Oeste — o quedarte para siempre.

**Puntuación máxima:** 250 puntos.

## Cómo funciona

El juego es autocontenido: no requiere servidor ni dependencias externas. Abre `el_muro.html` en cualquier navegador moderno.

El parser acepta órdenes en español: `COGER`, `DEJAR`, `EXAMINAR`, `IR`, `HABLAR CON`, `USAR`, `GUARDAR`, `CARGAR`, `AYUDA`.
